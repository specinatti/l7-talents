1. Visão Geral do Projeto

L7 Talents é um portal completo de RH com duas frentes: candidatos (buscam emprego) e empregadores (publicam vagas e contratam). O projeto está em produção no Railway e em desenvolvimento ativo.

Propósito: Ser um portal de recrutamento profissional competitivo com os grandes do mercado (LinkedIn, Indeed, Gupy), com foco no mercado brasileiro.

Diferenciais já implementados: match de perfil com vagas (Top/High/Bom/Low como o LinkedIn), pagamento via Mercado Pago, notificações por WhatsApp via Z-API, autenticação com OTP por email, 2FA, proteção por plano para empregadores.

✅ Status atual

  • Código 100% no GitHub
  • Banco PostgreSQL no Railway
  • Deploy automático via Railway
  • 7 usuários cadastrados
  • Backup do banco salvo no repo

⚠️ Pendências críticas

  • Modelo free vs pago para candidato não definido
  • Empregador pode registrar sem pagar (bug)
  • Perfil público de candidato não existe
  • Easy Apply não implementado
  • Timeline de candidatura ausente

4. Banco de Dados

PostgreSQL 18 no Railway em produção. Localmente PostgreSQL 16 na porta 5432. O schema é idempotente (CREATE TABLE IF NOT EXISTS) e roda automaticamente no start.

TabelaPropósitoColunas principais
usersTodos os usuáriosemail, password_hash, role (candidato/empregador/rh/financeiro/admin), plano_ativo, plano_expira_em, totp_secret, totp_enabled, senha_temporaria
candidatosPerfil do candidatonome, habilidades (text[]), nivel_experiencia, area_atuacao, modalidade, pretensao_salarial, cargo_desejado, curriculo_url, foto_url, disponivel_para_trabalho
empregadoresPerfil da empresarazao_social, nome_fantasia, logo_url, site, setor, porte, descricao, whatsapp
experienciasHistórico profissionalcandidato_id, empresa, cargo, data_inicio, data_fim, atual, descricao
formacoesFormação acadêmicacandidato_id, instituicao, curso, nivel, data_inicio, em_andamento
vagasVagas de empregotitulo, descricao, requisitos, beneficios, area, nivel, modalidade, tipo_contrato, salario_min, salario_max, habilidades (text[]), status (ativa/pausada/encerrada), destaque
candidaturasCandidato → Vagavaga_id, candidato_id, status (enviada/visualizada/em_analise/entrevista/aprovado/reprovado), carta_apresentacao, feedback
mensagensChat internocandidatura_id, remetente_id, conteudo, lida
vagas_salvasFavoritos do candidatocandidato_id, vaga_id
notificacoesAlertas in-appuser_id, tipo, titulo, mensagem, lida, link
pedidosCompras/pagamentospacote, valor, status (pendente/aprovado/recusado), mp_preference_id, mp_payment_id, email_comprador
page_viewsAnalytics básicopage, device, created_at
password_resetsReset de senhatoken, expires_at, used
email_otpOTP 2FAuser_id, code, expires_at, used
comunicadosAvisos internos RHtitulo, conteudo, created_at
Migrations incrementais: rodadas automaticamente no start via ALTER TABLE ... ADD COLUMN IF NOT EXISTS no src/db/index.js. Colunas adicionadas pós-schema inicial: disponivel_para_trabalho, totp_secret, totp_enabled, plano_ativo, plano_expira_em, senha_temporaria, whatsapp, email_alternativo.
